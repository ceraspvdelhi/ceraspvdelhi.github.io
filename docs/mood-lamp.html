Mood lamp

A colour-changing lamp. Touch it to change its mood.

Needs 220 Ω resistors35 minLevel ★★★

What you will make

An RGB LED is three LEDs in one: red, green and blue. It has four legs. The longest leg is the shared one, which goes to ground. By lighting each colour a little or a lot, you can make any colour. Each colour leg needs a 220 Ω resistor.

No resistors? This one needs the three resistors. Without them the RGB LED must stay unplugged. You can still run the sketch with HAVE_RESISTORS set to 0: it prints the mood names and blinks the light on the Nano once for mood 1, twice for mood 2 and so on.

What you need

  • 1Arduino Nano + base board
  • 1RGB LED
  • 1Touch sensor module
  • 1Breadboard
  • 3Resistor 220 Ω (not in the box)
  • 7Jumpers: 4 male-female, 3 female-female

Where to get 220 Ω resistors

Each part is described on Equipment.

Build it

  1. Unplug the USB. Push the RGB LED into the breadboard with each leg in its own row. The longest leg is the one second from the flat side.
  2. Put a 220 Ω resistor from each of the three shorter legs to an empty row.
  3. Run jumpers: D9 S to the red resistor, D10 S to green, D11 S to blue. The long leg goes to the G rail.
  4. Wire the touch sensor to D7 as in Project 3.
  5. Upload. The lamp starts as a rainbow. Touch to move to Calm, Happy, Sleepy and Excited.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other. The long leg of each LED goes to the resistor side.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Start here page.

Mood lamp
// Project 10: Mood lamp
// RGB LED: red on D9, green on D10, blue on D11, each through a 220 ohm resistor.
// The long leg of the LED goes to ground (common cathode).
// Touch sensor on D7 changes the mood.
//
// If the colours look inverted (you expected off and it is bright), your LED is
// "common anode": connect the long leg to 5V and set COMMON_ANODE to true.
//
// No resistors yet? Set HAVE_RESISTORS to 0. The sketch will not light the RGB LED;
// it only prints the colour names in the Serial Monitor.

#define HAVE_RESISTORS 1
const bool COMMON_ANODE = false;

const int RED_PIN = 9;
const int GREEN_PIN = 10;
const int BLUE_PIN = 11;
const int TOUCH_PIN = 7;

const char* moodName[] = {"Rainbow", "Calm", "Happy", "Sleepy", "Excited"};
const int moodColour[][3] = {
  {0, 0, 0},         // rainbow (changes by itself)
  {0, 80, 255},      // calm: blue
  {255, 180, 0},     // happy: yellow
  {120, 0, 200},     // sleepy: purple
  {255, 30, 30}      // excited: red
};
const int MOODS = 5;

int mood = 0;
bool wasTouched = false;

void show(int r, int g, int b) {
#if HAVE_RESISTORS
  if (COMMON_ANODE) { r = 255 - r; g = 255 - g; b = 255 - b; }
  analogWrite(RED_PIN, r);
  analogWrite(GREEN_PIN, g);
  analogWrite(BLUE_PIN, b);
#endif
}

// hue 0..767 around the colour wheel
void wheel(int h) {
  h = h % 768;
  if (h < 256)      show(255 - h, h, 0);
  else if (h < 512) show(0, 255 - (h - 256), h - 256);
  else              show(h - 512, 0, 255 - (h - 512));
}

void setup() {
  pinMode(TOUCH_PIN, INPUT);
#if HAVE_RESISTORS
  pinMode(RED_PIN, OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
  pinMode(BLUE_PIN, OUTPUT);
#endif
  pinMode(LED_BUILTIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Mood lamp ready. Touch to change the mood.");
  Serial.println("Mood: Rainbow");
}

void loop() {
  bool touched = digitalRead(TOUCH_PIN) == HIGH;
  if (touched && !wasTouched) {
    mood = (mood + 1) % MOODS;
    Serial.print("Mood: ");
    Serial.println(moodName[mood]);
    for (int i = 0; i < mood; i++) {     // the board light blinks the mood number
      digitalWrite(LED_BUILTIN, HIGH);
      delay(80);
      digitalWrite(LED_BUILTIN, LOW);
      delay(80);
    }
  }
  wasTouched = touched;

  if (mood == 0) {
    static int hue = 0;
    wheel(hue);
    hue = (hue + 2) % 768;
    delay(15);
  } else {
    show(moodColour[mood][0], moodColour[mood][1], moodColour[mood][2]);
    delay(15);
  }
}

What you should see

A slowly changing rainbow. Each touch picks a steady mood colour. After the fifth touch the rainbow is back.

How it works

  • analogWrite(pin, 0 to 255) switches the pin on and off thousands of times a second. 255 is always on, 0 is off, and the numbers between give a dimmer LED. Only pins marked with ~ on the Nano can do this: D3, D5, D6, D9, D10 and D11.
  • Mix red 255, green 180, blue 0 and you get yellow. The mood table keeps one colour per mood.
  • wheel() walks around the colour wheel: red fades into green, green into blue, blue back to red.

If it does not work

The colours look wrong or inverted.

Your LED may be a common anode type. Connect the long leg to 5V instead of ground and set COMMON_ANODE to true.

One colour is missing.

That leg is in the wrong row, or the resistor does not share a row with it.

The breadboard part does not work.

The five holes in one short row are joined together. Make sure the LED leg and the resistor leg share a row, and not a column of the other half.
