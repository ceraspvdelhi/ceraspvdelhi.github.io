Hello Nano

Make the little light on your Nano blink, and make it talk.

No extra parts needed10 minLevel ★☆☆

What you will make

This is the first one for everybody. There is nothing to wire. The Nano has a small light on the board that is connected to pin 13, and you are going to tell it when to go on and off. You will also make the Nano send a message to your computer.

What you need

  • 1Arduino Nano
  • 1USB cable

Each part is described on Equipment.

Build it

  1. Plug the Nano into the base board if it is not already, with the USB socket at the edge. The Start here page shows how.
  2. Plug the USB cable into the Nano and into the computer.
  3. Open the Arduino IDE, paste the code below over everything that is already there, and press Upload (the arrow).
  4. When it says Done uploading, the light on the board blinks once a second.
  5. Open the Serial Monitor (the magnifying glass at the top right, set to 9600 baud) and read what your Nano says.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Start here page.

Hello Nano
// Project 1: Hello Nano
// The little orange light on your Nano is wired to pin 13.
// This sketch blinks it and says hello in the Serial Monitor.

const int LED_PIN = LED_BUILTIN;   // the light on the board (pin 13)
const int ON_TIME = 500;           // how long the light stays on, in milliseconds
const int OFF_TIME = 500;          // how long it stays off

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Hello from my Nano!");
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  Serial.println("light ON");
  delay(ON_TIME);

  digitalWrite(LED_PIN, LOW);
  Serial.println("light OFF");
  delay(OFF_TIME);
}

What you should see

The light on the board blinks once a second, and the Serial Monitor prints "light ON", "light OFF" in turn.

How it works

  • setup() runs once, when the Nano starts. We tell pin 13 it is an OUTPUT and start the Serial connection.
  • loop() runs again and again for ever. digitalWrite(LED_PIN, HIGH) switches the light on, delay(500) waits half a second, then LOW switches it off.
  • Serial.println() sends a line of text down the USB cable. That is how a robot tells you what it is doing.

Try this

  • Change ON_TIME to 100 and OFF_TIME to 900. What does it look like now?
  • Make it blink SOS: three short, three long, three short.
  • Change the message in Serial.println to your own name.

If it does not work

The upload fails with a red message.

In Tools, set Processor to ATmega328P (Old Bootloader) and pick the right Port. Try another USB port. The Start here page has the full list.

The Serial Monitor shows funny symbols.

Set the speed at the bottom right of the Serial Monitor to 9600 baud.

The light never blinks but the upload said Done.

On some boards the light is dim. Look from the side in a dark room. If it is still off, upload again.
