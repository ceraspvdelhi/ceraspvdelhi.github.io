Which buzzer? And a doorbell

Find out what kind of buzzer you have, then make a tune.

No extra parts20 minLevel ★☆☆

What you will make

Buzzers come in two kinds. An active buzzer makes one fixed sound when it gets power. A passive buzzer is like a tiny speaker: you give it a pitch and it plays that note. Only a passive one can play tunes, so the first sketch tells you which one you have.

What you need

  • 1Arduino Nano + base board
  • 1Buzzer
  • 1Breadboard
  • 1Touch sensor module (part B)
  • 5Jumpers: 2 male-female, 3 female-female

Each part is described on Equipment.

Build it

  1. Unplug the USB. Push the buzzer into the breadboard, one leg in each of two different rows. The longer leg is the + leg.
  2. Run a male-female jumper from D8 S on the base board to the row of the long leg. Run another from a G pin to the row of the short leg.
  3. Upload part A (Which buzzer?) and listen for about ten seconds.
  4. Read the table below, then set ACTIVE_BUZZER in part B to true or false.
  5. Wire the touch sensor to D7 with three female-female jumpers, as in Project 3, upload part B and touch the pad.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Getting started page.

Part A: Which buzzer do I have?
// Project 5, part A: Which buzzer do I have?
// Buzzer: long leg (+) to D8, short leg to GND.
//
// Listen to the two tests, then read the table on the project page.
//   Test A: the pin goes HIGH and stays HIGH for one second.
//   Test B: the pin plays a rising scale, C D E F G.

const int BUZZER_PIN = 8;

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Which buzzer do I have?");
}

void loop() {
  Serial.println("Test A: steady power for 1 second. Do you hear a beep?");
  digitalWrite(BUZZER_PIN, HIGH);
  delay(1000);
  digitalWrite(BUZZER_PIN, LOW);
  delay(1500);

  Serial.println("Test B: a scale, going up. Does the pitch change?");
  int notes[] = {262, 294, 330, 349, 392};
  for (int i = 0; i < 5; i++) {
    tone(BUZZER_PIN, notes[i], 300);
    delay(400);
  }
  noTone(BUZZER_PIN);
  delay(2500);
}
Part B: Doorbell
// Project 5, part B: Doorbell
// Touch sensor on D7, buzzer on D8 (long leg to the signal pin).
// Touch the sensor and the doorbell plays a short tune.
//
// Set ACTIVE_BUZZER to true if Part A told you your buzzer is the "active" kind.
// It will then play the rhythm only, with the same sound for every note.

const bool ACTIVE_BUZZER = false;

const int TOUCH_PIN = 7;
const int BUZZER_PIN = 8;

void note(int pitch, int ms) {
  if (ACTIVE_BUZZER) {
    digitalWrite(BUZZER_PIN, HIGH);
    delay(ms);
    digitalWrite(BUZZER_PIN, LOW);
  } else {
    tone(BUZZER_PIN, pitch, ms);
    delay(ms);
    noTone(BUZZER_PIN);
  }
  delay(40);
}

void ding() {
  note(659, 250);   // E
  note(523, 250);   // C
  note(587, 250);   // D
  note(392, 500);   // G
}

void setup() {
  pinMode(TOUCH_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Doorbell ready. Touch the sensor.");
}

void loop() {
  if (digitalRead(TOUCH_PIN) == HIGH) {
    Serial.println("Ding dong!");
    ding();
    delay(500);
  }
}

Test A: silence or a small click. Test B: five different notes going upPassive. Leave ACTIVE_BUZZER as false. You can play tunes.
Nothing at allFlip the legs, and check D8 S and G. Press the legs firmly into the breadboard.

What you should see

Part A beeps and plays a scale, over and over. Part B plays a four note doorbell tune when you touch the pad.

How it works

  • digitalWrite(HIGH) on a buzzer is plain power. An active buzzer has its own oscillator inside and starts to sing. A passive one just clicks.
  • tone(pin, pitch, ms) makes the Nano switch the pin on and off very fast, hundreds of times a second. The pitch is the number of switches a second, in Hz. A passive buzzer turns that into a note.
  • The note() helper picks the right way for your buzzer, so the doorbell code stays tidy.

If it does not work

The buzzer is quiet.

Active buzzers are loud on 5 V. If it clicks, it is probably a passive one.

The breadboard part does not work.

The five holes in one short row are joined together. Make sure the LED leg and the resistor leg share a row, and not a column of the other half.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.
