Secret knock lock

Short, short, long. Only you know the knock that opens it.

No extra parts needed30 minLevel ★★★

What you will make

This lock listens to how long you touch the pad. Short and long touches make a code. The light on the board shows the lock: off means locked, on for three seconds means open. You can change the code to your own pattern.

What you need

  • 1Arduino Nano + base board
  • 1Touch sensor module
  • 1Buzzer (optional)
  • 1Breadboard
  • 5Jumpers: 2 male-female, 3 female-female

Each part is described on Equipment.

Build it

  1. Unplug the USB.
  2. Wire the touch sensor to D7 and the buzzer to D8.
  3. Upload, open the Serial Monitor, and try: short, short, long.
  4. Change SECRET and CODE_LENGTH and make your own.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Start here page.

Secret knock lock
// Project 13: Secret knock lock
// Touch sensor on D7. Buzzer on D8 (optional). The light on the board is the lock:
// off = locked, on for 3 seconds = open.
//
// The secret: short, short, long. A short touch is under 300 ms, a long touch is 300 ms or more.
// Change SECRET and CODE_LENGTH to make your own.

const int TOUCH_PIN = 7;
const int BUZZER_PIN = 8;
const int LONG_MS = 300;
const int IDLE_RESET_MS = 3000;

const char SECRET[] = "SSL";
const int CODE_LENGTH = 3;

char entered[8];
int count = 0;
unsigned long lastTouch = 0;

void openLock() {
  Serial.println("UNLOCKED!");
  digitalWrite(LED_BUILTIN, HIGH);
  tone(BUZZER_PIN, 880, 150);
  delay(200);
  tone(BUZZER_PIN, 1320, 300);
  delay(3000);
  digitalWrite(LED_BUILTIN, LOW);
}

void wrongCode() {
  Serial.println("Wrong code. Locked.");
  tone(BUZZER_PIN, 150, 500);
  delay(600);
}

void setup() {
  pinMode(TOUCH_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(LED_BUILTIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Locked. Knock the secret.");
}

void loop() {
  if (count > 0 && millis() - lastTouch > IDLE_RESET_MS) {
    Serial.println("Took too long. Starting over.");
    count = 0;
  }

  if (digitalRead(TOUCH_PIN) == HIGH) {
    unsigned long down = millis();
    while (digitalRead(TOUCH_PIN) == HIGH) {
      delay(5);
    }
    unsigned long held = millis() - down;
    lastTouch = millis();

    char c = (held >= LONG_MS) ? 'L' : 'S';
    Serial.print("touch: ");
    Serial.println(c == 'L' ? "long" : "short");
    entered[count] = c;
    count++;

    if (count == CODE_LENGTH) {
      bool ok = true;
      for (int i = 0; i < CODE_LENGTH; i++) {
        if (entered[i] != SECRET[i]) ok = false;
      }
      if (ok) openLock();
      else wrongCode();
      count = 0;
    }
  }
}

What you should see

The Serial Monitor prints each touch, and then UNLOCKED! or Wrong code. The light stays on three seconds when it opens.

How it works

  • We measure how long the pin stays HIGH. 300 ms or more is a long touch, less is short.
  • Each touch goes into the entered[] list. When the list is as long as the code, we compare it letter by letter with SECRET.
  • If you wait more than three seconds the list is cleared, so a half-finished code does not hang around.

If it does not work

Short touches count as long.

Raise LONG_MS to 400 or 500.

It counts one touch twice.

Rest your finger on the pad. Small taps can bounce. Try a firmer press.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.
