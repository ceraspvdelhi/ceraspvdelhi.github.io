Touch lamp

Touch to switch a light on. Touch again to switch it off.

Resistor optional15 minLevel ★☆☆

What you will make

The touch sensor has a small pad on it. When your finger lands on the pad, the signal pin goes HIGH. Here we use that as a switch for the light on the Nano. If you buy a resistor later, you can swap in a real LED.

No resistors? This project needs no resistor because it uses the light on the Nano. To use a real LED, plug it into D4 with a 220 Ω resistor as in the traffic light, and change LED_PIN to 4 in the code.

What you need

  • 1Arduino Nano + base board
  • 1Touch sensor module
  • 3Female-female jumpers
  • 1Optional: LED, 220 Ω resistor, breadboard

Each part is described on Equipment.

Build it

  1. Unplug the USB.
  2. Connect three female-female jumpers from the base board D7 triplet to the touch sensor: S to the I/O pin, V to VCC, G to GND.
  3. Plug in the USB, upload, and touch the pad on the sensor with a fingertip.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Start here page.

Touch lamp
// Project 3: Touch lamp
// Touch the sensor once: the lamp turns on. Touch again: it turns off.
// Touch sensor signal on D7.
//
// LED_BUILTIN is the light on the Nano, so this works with no extra parts.
// To use a real LED (with a 220 ohm resistor), plug it into D4 and
// change the next line to:  const int LED_PIN = 4;

const int TOUCH_PIN = 7;
const int LED_PIN = LED_BUILTIN;

bool lampOn = false;
bool wasTouched = false;

void setup() {
  pinMode(TOUCH_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Touch lamp ready");
}

void loop() {
  bool touched = digitalRead(TOUCH_PIN) == HIGH;

  // act only at the moment the finger lands, not while it stays there
  if (touched && !wasTouched) {
    lampOn = !lampOn;
    digitalWrite(LED_PIN, lampOn ? HIGH : LOW);
    Serial.println(lampOn ? "lamp ON" : "lamp OFF");
    delay(50);   // ignore tiny bounces
  }
  wasTouched = touched;
}

What you should see

One touch and the lamp goes on, the next touch and it goes off. The Serial Monitor says the same.

How it works

  • digitalRead tells us if the pin is HIGH (touched) or LOW.
  • If we only checked "is it touched", the lamp would flicker on and off while your finger rests. So we remember the last state in wasTouched and act only at the moment the finger lands.
  • lampOn = !lampOn flips between true and false every time.

If it does not work

It switches on its own.

Keep your hand away from the board and the wires. Touch sensors can feel static. A shorter wire helps.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.

The upload fails with a red message.

In Tools, set Processor to ATmega328P (Old Bootloader) and pick the right Port. Try another USB port. The Start here page has the full list.
