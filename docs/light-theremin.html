Light theremin

Play music with your hand, without touching anything.

No extra parts needed20 minLevel ★★★

What you will make

A theremin is a real instrument you play by moving your hands near it. This one reads the light. Cover the sensor and the pitch falls, uncover it and the pitch rises. It sounds best on a passive buzzer. An active buzzer only gives a beeper that changes speed.

What you need

  • 1Arduino Nano + base board
  • 1Light sensor module
  • 1Buzzer (passive works best)
  • 1Breadboard
  • 5Jumpers: 2 male-female, 3 female-female

Each part is described on Equipment.

Build it

  1. Unplug the USB. Wire the buzzer to D8 and the light sensor to A0, as in Projects 4 and 5.
  2. Upload and open the Serial Monitor to see the numbers for covered and uncovered.
  3. Put those numbers in LOW_READING and HIGH_READING, and upload again.
  4. If you found out in Project 5 that you have an active buzzer, set ACTIVE_BUZZER to true.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Start here page.

Light theremin
// Project 12: Light theremin
// Light sensor module on A0, buzzer on D8 (long leg to the signal pin).
// Move your hand over the sensor to change the pitch.
//
// This needs the "passive" buzzer from Project 5 for different notes.
// With an active buzzer, set ACTIVE_BUZZER to true: you get a beeper that
// speeds up as it gets darker.
//
// Open the Serial Monitor and read the numbers when the sensor is covered
// and uncovered. Put them into LOW_READING and HIGH_READING.

const bool ACTIVE_BUZZER = false;

const int LDR_PIN = A0;
const int BUZZER_PIN = 8;
const int LOW_READING = 100;
const int HIGH_READING = 900;
const int LOW_PITCH = 200;
const int HIGH_PITCH = 2000;

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Light theremin ready");
}

void loop() {
  int light = analogRead(LDR_PIN);
  light = constrain(light, LOW_READING, HIGH_READING);

  if (ACTIVE_BUZZER) {
    int gap = map(light, LOW_READING, HIGH_READING, 50, 600);
    digitalWrite(BUZZER_PIN, HIGH);
    delay(40);
    digitalWrite(BUZZER_PIN, LOW);
    delay(gap);
  } else {
    int pitch = map(light, LOW_READING, HIGH_READING, LOW_PITCH, HIGH_PITCH);
    tone(BUZZER_PIN, pitch);
    delay(30);
  }

  Serial.println(light);
}

What you should see

The pitch swoops up and down as you move your hand over the sensor.

How it works

  • constrain() keeps the reading inside our range, so the map is never out of bounds.
  • map(light, 100, 900, 200, 2000) turns a light reading into a pitch between 200 and 2000 Hz.
  • tone(pin, pitch) with no length keeps playing until the next call.

Try this

  • Flip the direction so more light gives a lower note.
  • Round the pitch to the nearest note of a scale.
  • Add the ultrasonic sensor and play it as a second instrument.

If it does not work

The note never changes.

Check the numbers in the Serial Monitor. If the reading hardly moves, shine a torch from the side.

Only a click.

You may have an active buzzer. Set ACTIVE_BUZZER to true.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.
