Finished the 15? These are good places to go next.

Start here

  • Arduino Nano page: Official guide to your board.
  • Arduino IDE download: The program you write code in.
  • Arduino Learn: Tutorials from the Arduino team, from first steps up.
  • Built-in examples: Short, well explained example programs. The IDE has them under File, Examples.

More projects to build

  • Arduino Project Hub (Nano): Thousands of projects shared by makers, filtered for the Nano.
  • Random Nerd Tutorials: Step by step Arduino projects with wiring pictures.
  • Adafruit Learn: Long, friendly guides.
  • Instructables: Arduino: Projects from people all over the world.

Try circuits without wires

  • Tinkercad Circuits: Free. Build and run Arduino circuits in your browser before you touch a wire.

Look up how code works

  • Arduino language reference: Every function with a short example.
  • Arduino on YouTube: Videos from the Arduino team.

Make your own project

  1. Pick one of the 15 and change one thing. A different sensor, a different sound, a different rule.
  2. Draw what should happen before you write code: "when this, then that".
  3. Get one part working at a time. Check it in the Serial Monitor.
  4. When it works, write down the wiring so you can build it again.
