Traffic light

Three LEDs that stop, get ready and go, just like the one on the road.

Needs 220 Ω resistors25 minLevel ★★☆

What you will make

An LED lets current through in one direction only, and it needs a resistor in front of it or it will burn out. That is why this project needs three 220 Ω resistors. They are not in the box, but any electronics shop will sell them. Resistors from 150 Ω to 470 Ω all work.

No resistors? Open the code, change the line #define HAVE_RESISTORS 1 to 0 and upload. You only need the Nano. The light on the board becomes the traffic light: steady means stop, a fast blink means get ready, a slow blink means go.

What you need

  • 1Arduino Nano + base board
  • 1LED: red
  • 1LED: yellow
  • 1LED: green
  • 1Breadboard
  • 3Resistor 220 Ω (not in the box)
  • 6Jumper wires, male to female

Where to get 220 Ω resistors

Each part is described on Equipment.

Build it

  1. Unplug the USB first. Always change wires with the power off.
  2. Push the three LEDs into the breadboard in a row, a few columns apart. The long leg of each LED goes on the left, the short leg on the right.
  3. Put a 220 Ω resistor from the long-leg column of each LED to an empty column to its left.
  4. Run a male-female jumper from D2 S on the base board (female end on the base board) to the resistor of the red LED. D3 S goes to yellow, D4 S to green.
  5. Run a jumper from any G pin to the blue rail of the breadboard, then a short wire from each short leg to the rail.
  6. Plug in the USB and upload the code.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other. The long leg of each LED goes to the resistor side.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Getting started page.

Traffic light
// Project 2: Traffic light
// Three LEDs, each with its own 220 ohm resistor: red on D2, yellow on D3, green on D4.
//
// No resistors yet? Change the next line to 0. The light on the board
// will do the job of all three: steady = stop, fast blink = get ready, slow blink = go.

#define HAVE_RESISTORS 1

const int RED_PIN = 2;
const int YELLOW_PIN = 3;
const int GREEN_PIN = 4;

const int STOP_TIME = 4000;     // milliseconds
const int READY_TIME = 1500;
const int GO_TIME = 4000;

#if HAVE_RESISTORS
void lights(bool r, bool y, bool g) {
  digitalWrite(RED_PIN, r);
  digitalWrite(YELLOW_PIN, y);
  digitalWrite(GREEN_PIN, g);
}
#else
// One light only: show the state with a blink pattern.
void blinkFor(int total, int period) {
  unsigned long start = millis();
  while (millis() - start < (unsigned long)total) {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(period / 2);
    digitalWrite(LED_BUILTIN, LOW);
    delay(period / 2);
  }
}
#endif

void setup() {
  Serial.begin(9600);
#if HAVE_RESISTORS
  pinMode(RED_PIN, OUTPUT);
  pinMode(YELLOW_PIN, OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
#else
  pinMode(LED_BUILTIN, OUTPUT);
#endif
  Serial.println("Traffic light ready");
}

void loop() {
#if HAVE_RESISTORS
  Serial.println("STOP");
  lights(true, false, false);
  delay(STOP_TIME);

  Serial.println("GET READY");
  lights(true, true, false);
  delay(READY_TIME);

  Serial.println("GO");
  lights(false, false, true);
  delay(GO_TIME);

  Serial.println("SLOW DOWN");
  lights(false, true, false);
  delay(READY_TIME);
#else
  Serial.println("STOP (steady light)");
  digitalWrite(LED_BUILTIN, HIGH);
  delay(STOP_TIME);

  Serial.println("GET READY (fast blink)");
  blinkFor(READY_TIME, 200);

  Serial.println("GO (slow blink)");
  blinkFor(GO_TIME, 1000);
#endif
}

What you should see

Red for four seconds, red and yellow, green for four seconds, yellow, and round again. The Serial Monitor names each stage.

How it works

  • Each LED has its own pin. lights(true, false, false) means red on, yellow off, green off.
  • The loop goes STOP, GET READY (red and yellow together, like in many countries), GO, SLOW DOWN, and then starts again.
  • The times are constants at the top. Change them and the whole light changes, with nothing else to touch.

Try this

  • Make the green light longer than the red one.
  • Add the touch sensor from the box as a crossing button: when somebody touches it, finish the green and go to red sooner.
  • Make the yellow light blink three times before it goes red.

If it does not work

One LED stays dark.

LEDs only work one way round. Turn it around, long leg to the resistor side.

The breadboard part does not work.

The five holes in one short row are joined together. Make sure the LED leg and the resistor leg share a row, and not a column of the other half.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.
