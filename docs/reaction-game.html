Reaction game

How fast are you? The Nano times you to the millisecond.

No extra parts20 minLevel ★★☆

What you will make

Touch the sensor to start. After a random wait the light on the board comes on. Touch again as fast as you can. A good time is under 300 ms. If you touch before the light, you lose the round.

What you need

  • 1Arduino Nano + base board
  • 1Touch sensor module
  • 1Buzzer (optional)
  • 3Female-female jumpers

Each part is described on Equipment.

Build it

  1. Unplug the USB.
  2. Wire the touch sensor to D7 as in Project 3. Optional: wire the buzzer to D8.
  3. Upload, open the Serial Monitor, and touch the sensor to play.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Getting started page.

Reaction game
// Project 11: Reaction game
// Touch sensor on D7. The light on the board is the signal (no resistor needed).
// Wait for the light, then touch as fast as you can. Touch too early and you lose.
// Optional buzzer on D8 gives a beep when the light comes on.

const int TOUCH_PIN = 7;
const int BUZZER_PIN = 8;
const int LED_PIN = LED_BUILTIN;

unsigned long best = 99999;

void setup() {
  pinMode(TOUCH_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  Serial.begin(9600);
  randomSeed(analogRead(A5));
  Serial.println("Reaction game! Touch the sensor to start a round.");
}

void waitForTouch(bool wanted) {
  while ((digitalRead(TOUCH_PIN) == HIGH) != wanted) {
    delay(5);
  }
}

void loop() {
  waitForTouch(true);
  waitForTouch(false);           // let go first
  Serial.println("Get ready...");
  delay(300);

  unsigned long waitTime = random(2000, 6000);
  unsigned long start = millis();
  while (millis() - start < waitTime) {
    if (digitalRead(TOUCH_PIN) == HIGH) {
      Serial.println("Too early! Round over.");
      waitForTouch(false);
      return;
    }
  }

  digitalWrite(LED_PIN, HIGH);
  tone(BUZZER_PIN, 1500, 80);    // quiet on an active buzzer if it has no tone, harmless
  unsigned long t0 = millis();
  while (digitalRead(TOUCH_PIN) == LOW) {
    if (millis() - t0 > 3000) break;
  }
  unsigned long ms = millis() - t0;
  digitalWrite(LED_PIN, LOW);

  if (ms > 3000) {
    Serial.println("Too slow. Touch to try again.");
    return;
  }
  Serial.print("Your time: ");
  Serial.print(ms);
  Serial.println(" ms");
  if (ms < best) {
    best = ms;
    Serial.println("NEW BEST!");
  }
  Serial.print("Best so far: ");
  Serial.print(best);
  Serial.println(" ms");
  Serial.println("Touch to play again.");
}

What you should see

The Serial Monitor says "Get ready", then the light comes on and it prints your time, for example "Your time: 287 ms".

How it works

  • millis() tells us how long the Nano has been on, in milliseconds. We read it when the light comes on and again when you touch, and subtract.
  • random(2000, 6000) gives a different wait every time, so you cannot guess.
  • best remembers the best time until you unplug the board.

If it does not work

It always says Too early.

Your finger may still be on the pad, or the sensor is touching something. Let go and start again.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.

The Serial Monitor shows funny symbols.

Set the speed at the bottom right of the Serial Monitor to 9600 baud.
