Start here

Set up your Arduino board before starting a project.

1. Put the Nano on its base board

  1. Hold the base board with its screw terminals and pin rows facing up. Look for the USB socket drawing on it.
  2. Press the Nano into the two long rows of sockets, with the Nano's USB socket at the same end as the drawing. Press evenly. Never force it.
  3. If your base board has a little jumper or switch marked 3.3V and 5V, set it to 5V.
The base board gives every pin three sockets in a row: S (signal), V (5 volts) and G (ground). Most modules plug in with three jumpers, one to each. That is why we say "wire it to the D7 triplet".

2. Install the Arduino IDE

  1. Go to arduino.cc/en/software and download the Arduino IDE (version 2 is fine) for your computer.
  2. Install it and open it. Nothing else to install for these projects. No libraries.

3. Plug in and pick the board

  1. Plug the USB cable into the Nano and into the computer. A power light comes on.
  2. In the IDE, open Tools, then Board, and choose Arduino Nano.
  3. In Tools, then Processor, choose ATmega328P (Old Bootloader). Most Nano boards sold in India need this one. If the upload fails later, try the other choice.
  4. In Tools, then Port, choose the port that appeared when you plugged in. On a Mac it looks like /dev/cu.usbserial or wchusbserial. On Windows it is COM3 or another COM number.
No port appears? Your Nano probably uses a CH340 chip and your computer needs its driver. Search for "CH340 driver" for your system, install it, unplug the Nano and plug it back in. Also try another USB cable if you have one. Some cables only charge.

4. Your first upload

  1. Open Project 1: Hello Nano. Copy the code.
  2. In the IDE delete everything in the editor window and paste.
  3. Press the arrow (Upload). The light on the board flickers while it sends. Wait for "Done uploading".
  4. Open the Serial Monitor (magnifying glass, top right) and set 9600 baud at the bottom right. You should see your Nano talking.

5. Rules of the bench

  • Unplug the USB before you move any wire. Wires first, USB last.
  • Red is power, dark is ground. Do not let the two touch.
  • An LED always needs a resistor, unless you use the light that is already on the Nano.
  • Take the water sensors out of the water and dry them when you are done.

When the upload fails

avrdude: stk500_getsync(): not in sync

Change Processor to the other bootloader choice. Check the Port. Unplug the Nano and try another USB port.

Port is greyed out or missing

Install the CH340 driver (see above), and try another cable.

Compile error

The code was not pasted whole. Delete everything in the editor, copy again with the Copy code button, and paste. If it says "undefined reference to setup and loop", this is the cause.

It uploads, nothing happens

Open the Serial Monitor at 9600. If it prints, the Nano is fine and the problem is a wire. Check each wire against the table on the project page.
