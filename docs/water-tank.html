Water tank monitor

Empty, low, half or full, shown on the screen and with a beep.

No extra parts needed25 minLevel ★★☆

What you will make

The water level sensor has a row of thin copper lines. The more of them are under water, the bigger the number. Only the lines go in the water. Keep the top part with the pins dry, and take the sensor out when you are done, because water slowly eats the copper.

What you need

  • 1Arduino Nano + base board
  • 1Water level sensor
  • 1Buzzer
  • 1Breadboard
  • 1A small cup of water
  • 5Jumpers: 2 male-female, 3 female-female

Each part is described on Equipment.

Build it

  1. Unplug the USB. Wire the buzzer to D8.
  2. Wire the sensor to the A1 triplet: S to S, V to +, G to -.
  3. Upload and dip the sensor into the cup a little at a time. Write down the numbers you see at about a quarter, half and full.
  4. Put your numbers in LOW_LEVEL, HALF_LEVEL and FULL_LEVEL and upload again.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Start here page.

Water tank monitor
// Project 9: Water tank monitor
// Water level sensor: S to A1, + to 5V, - to ground.
// Only the printed lines of the sensor go in the water, never the top.
//
// Step 1: upload and dip the sensor a little at a time. Watch the number rise.
// Step 2: put the numbers you saw into LOW_LEVEL, HALF_LEVEL and FULL_LEVEL.
// Buzzer on D8 sounds when the tank is full.

const int LEVEL_PIN = A1;
const int BUZZER_PIN = 8;
const int LOW_LEVEL = 100;
const int HALF_LEVEL = 250;
const int FULL_LEVEL = 400;
const bool ACTIVE_BUZZER = false;

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(LED_BUILTIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Tank monitor ready");
}

void loop() {
  int v = analogRead(LEVEL_PIN);

  const char* label;
  int bars;
  if (v >= FULL_LEVEL)      { label = "FULL";  bars = 4; }
  else if (v >= HALF_LEVEL) { label = "HALF";  bars = 3; }
  else if (v >= LOW_LEVEL)  { label = "LOW";   bars = 2; }
  else                      { label = "EMPTY"; bars = 1; }

  Serial.print("[");
  for (int i = 0; i < 4; i++) Serial.print(i < bars ? "#" : " ");
  Serial.print("] ");
  Serial.print(label);
  Serial.print("   (reading ");
  Serial.print(v);
  Serial.println(")");

  digitalWrite(LED_BUILTIN, bars == 1 ? HIGH : LOW);   // light on = refill

  if (bars == 4) {
    if (ACTIVE_BUZZER) digitalWrite(BUZZER_PIN, HIGH);
    else tone(BUZZER_PIN, 1000);
    delay(300);
    if (ACTIVE_BUZZER) digitalWrite(BUZZER_PIN, LOW);
    else noTone(BUZZER_PIN);
  }
  delay(500);
}

What you should see

The Serial Monitor shows [####] FULL, [### ] HALF and so on. When full, the buzzer beeps.

How it works

  • The reading rises with the water, so each level is a bigger number than the last. The if / else if chain starts with the biggest, so the first match wins.
  • The bar is built with a for loop that prints # for each filled level and a space for the rest.
  • The light on the Nano comes on when the tank is empty, which is when you need to refill.

Try this

  • Make a version that warns when the tank is nearly empty, with a different sound.
  • Make the bar longer, with eight levels.
  • Power the sensor from a digital pin so it is only on while reading. That keeps the copper from wearing.

If it does not work

The number is always 0.

The lines are not under water, or the S wire is loose. Check A1 S.

The numbers drift.

That is normal with this kind of sensor. Use the levels as a guide, not a measurement.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.
