Parking sensor

Beeps faster the closer you get, just like a car.

No extra parts needed25 minLevel ★★☆

What you will make

The ultrasonic sensor makes a sound too high for you to hear and times how long the echo takes to return. Sound travels about 29 microseconds for a centimetre, and the echo has to go there and back, so the distance in centimetres is the time divided by 58.

What you need

  • 1Arduino Nano + base board
  • 1Ultrasonic sensor (HC-SR04)
  • 1Buzzer
  • 1Breadboard
  • 6Jumpers: 2 male-female, 4 female-female

Each part is described on Equipment.

Build it

  1. Unplug the USB. Wire the buzzer to D8.
  2. The ultrasonic sensor has four pins: VCC, Trig, Echo, GND. Connect Trig to D9 S and Echo to D10 S.
  3. Connect VCC to D9 V and GND to D9 G. This borrows power from the D9 triplet.
  4. Upload and slide your hand toward the sensor. Watch the distance in the Serial Monitor.

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Start here page.

Parking sensor
// Project 7: Parking sensor
// Ultrasonic sensor: TRIG on D9, ECHO on D10, VCC to 5V, GND to ground.
// Buzzer on D8. The closer the car, the faster the beeps.

const int TRIG_PIN = 9;
const int ECHO_PIN = 10;
const int BUZZER_PIN = 8;
const int FAR_CM = 60;      // quiet beyond this
const int STOP_CM = 8;      // steady beep at this distance or closer
const bool ACTIVE_BUZZER = false;

int readCm() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  long us = pulseIn(ECHO_PIN, HIGH, 25000);   // give up after 25 ms
  if (us == 0) return 999;                    // nothing heard
  return us / 58;
}

void beep(int ms) {
  if (ACTIVE_BUZZER) digitalWrite(BUZZER_PIN, HIGH);
  else tone(BUZZER_PIN, 1000);
  delay(ms);
  if (ACTIVE_BUZZER) digitalWrite(BUZZER_PIN, LOW);
  else noTone(BUZZER_PIN);
}

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Parking sensor ready");
}

void loop() {
  int cm = readCm();
  Serial.print("distance: ");
  Serial.print(cm);
  Serial.println(" cm");

  if (cm <= STOP_CM) {
    beep(200);                       // steady tone
  } else if (cm < FAR_CM) {
    int gap = map(cm, STOP_CM, FAR_CM, 40, 700);   // closer = shorter gap
    beep(60);
    delay(gap);
  } else {
    delay(150);
  }
}

What you should see

Quiet beyond about 60 cm. Slow beeps as you come closer, fast beeps at 20 cm and a steady tone under 8 cm.

How it works

  • We send a 10 microsecond pulse on TRIG. The sensor sends its sound and raises ECHO for as long as the sound takes to come back.
  • pulseIn measures that time. It gives up after 25 ms, so the sketch does not hang when there is nothing to hear.
  • map() turns a distance into a waiting time: close means a short gap between beeps, far means a long one.

Try this

  • Change FAR_CM and STOP_CM to make it more sensitive.
  • Show the distance as a row of # signs.
  • Add the light on the Nano flashing in time with the beeps.

If it does not work

The distance always says 999.

Check that Trig and Echo are on D9 and D10 and not swapped. Check VCC and GND.

The numbers jump around.

Soft things like clothes absorb the sound. Try a flat wall or a book.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.
