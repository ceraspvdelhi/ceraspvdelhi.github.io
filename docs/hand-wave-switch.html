Hand-wave switch

Wave at the lamp to switch it. No buttons, no touching.

Resistor optional25 minLevel ★★★

What you will make

This works like the hand dryers in public toilets. The ultrasonic sensor measures the distance all the time. When a hand comes closer than 15 cm, the lamp changes: on becomes off, off becomes on.

No resistors? No resistor needed with the light on the Nano. For a real LED, use D4 with a 220 Ω resistor and set LED_PIN to 4.

What you need

  • 1Arduino Nano + base board
  • 1Ultrasonic sensor (HC-SR04)
  • 4Female-female jumpers
  • 1Optional: LED, 220 Ω resistor, breadboard

Each part is described on Equipment.

Build it

  1. Unplug the USB.
  2. Wire the sensor as in Project 7: Trig to D9 S, Echo to D10 S, VCC to D9 V, GND to D9 G.
  3. Upload, then hold your hand about 10 cm in front of the sensor and take it away.
  4. Do it again to switch back.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Getting started page.

Hand-wave switch
// Project 15: Hand-wave switch
// Ultrasonic sensor: TRIG on D9, ECHO on D10, VCC to 5V, GND to ground.
// Wave your hand 5 to 15 cm in front of the sensor to switch the lamp on or off.
//
// LED_BUILTIN is the light on the Nano. For a real LED with a 220 ohm resistor,
// plug it into D4 and change LED_PIN to 4.

const int TRIG_PIN = 9;
const int ECHO_PIN = 10;
const int LED_PIN = LED_BUILTIN;
const int NEAR_CM = 15;         // hand counts if it is closer than this

bool lampOn = false;
bool handThere = false;

int readCm() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  long us = pulseIn(ECHO_PIN, HIGH, 25000);
  if (us == 0) return 999;
  return us / 58;
}

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Hand-wave switch ready");
}

void loop() {
  int cm = readCm();
  bool near = cm < NEAR_CM;

  if (near && !handThere) {          // the hand just arrived
    lampOn = !lampOn;
    digitalWrite(LED_PIN, lampOn ? HIGH : LOW);
    Serial.print("hand at ");
    Serial.print(cm);
    Serial.println(lampOn ? " cm -> lamp ON" : " cm -> lamp OFF");
  }
  handThere = near;
  delay(60);
}

What you should see

Each wave toggles the lamp. The Serial Monitor tells you how far your hand was.

How it works

  • near is true when the distance is less than NEAR_CM.
  • We switch only at the moment the hand arrives (near && !handThere), the same trick as in the touch lamp.
  • Without that trick the lamp would flicker for as long as your hand stayed there.

Try this

  • Use a different distance for turning on and off.
  • Hold your hand there for two seconds to dim the lamp.
  • Put the sensor next to the light sensor and make the lamp work only in the dark.

If it does not work

Nothing happens.

Check the Serial Monitor. If the distance is always 999, Trig and Echo are swapped or VCC is loose.

It flips back and forth.

Something else is close to the sensor. Point it away from the wall.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.
