Rain alarm

Hang it out of the window and it tells you when the first drop falls.

No extra parts needed20 minLevel ★★☆

What you will make

The sensing pad has lots of thin copper lines. Water joins them together and lets current flow. The module turns that into a number: high when dry, lower when wet. Never put it in a bucket. A few drops are enough.

What you need

  • 1Arduino Nano + base board
  • 1Raindrop sensor module and sensing pad
  • 1Buzzer
  • 1Breadboard
  • 5Jumpers: 2 male-female, 3 female-female

Each part is described on Equipment.

Build it

  1. Unplug the USB. Connect the pad to the module with the two wire cable that came with it.
  2. Wire the buzzer to D8 as in Project 5.
  3. Connect the module to the A0 triplet: S to AO, V to VCC, G to GND. Leave the DO pin empty.
  4. Upload and open the Serial Monitor. A dry pad reads close to 1000. Touch it with a wet fingertip and watch the number fall.
  5. If it does not trigger, change WET_BELOW to a number between the dry and the wet reading.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Start here page.

Rain alarm
// Project 8: Rain alarm
// Rain module: AO to A0, VCC to 5V, GND to ground. The sensing pad plugs into the module.
// Buzzer on D8. Dry reads a big number (near 1000). Wet drops it.
//
// Upload, open the Serial Monitor, touch the pad with a wet finger and see how low the
// number goes. Put WET_BELOW somewhere in between.

const int RAIN_PIN = A0;
const int BUZZER_PIN = 8;
const int WET_BELOW = 700;
const bool ACTIVE_BUZZER = false;

void alarm() {
  for (int i = 0; i < 3; i++) {
    if (ACTIVE_BUZZER) digitalWrite(BUZZER_PIN, HIGH);
    else tone(BUZZER_PIN, 1200);
    delay(200);
    if (ACTIVE_BUZZER) digitalWrite(BUZZER_PIN, LOW);
    else noTone(BUZZER_PIN);
    delay(150);
  }
}

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(LED_BUILTIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Rain alarm ready. Drop some water on the pad.");
}

void loop() {
  int value = analogRead(RAIN_PIN);
  bool wet = value < WET_BELOW;

  Serial.print("rain reading: ");
  Serial.print(value);
  Serial.println(wet ? "   RAIN!" : "   dry");

  digitalWrite(LED_BUILTIN, wet ? HIGH : LOW);
  if (wet) alarm();
  delay(300);
}

What you should see

The Serial Monitor prints "dry" with a big number. When a drop lands on the pad it prints RAIN! and the buzzer beeps.

How it works

  • analogRead(A0) gives a number from 0 to 1023. Dry is high and wet is low, because water is a bad conductor and the module works the other way round from what you might expect.
  • The wet flag is just value < WET_BELOW.
  • alarm() beeps three times and then the loop reads the pad again.

Try this

  • Print how many times it rained.
  • Make it beep only once per shower, and not every cycle.
  • Dry the pad with a tissue. Does the number come back?

If it does not work

It rings when dry.

Raise or lower WET_BELOW. A pad that has been wet and is only damp reads lower than before.

The reading is stuck at 1023 or 0.

Check the cable between pad and module and the AO jumper.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.
