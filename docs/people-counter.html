People counter

Count everyone who walks through, and ring when it gets crowded.

No extra parts needed20 minLevel ★★☆

What you will make

The IR module sees something in front of it. A person walking past makes the output change once, and we add one to the count. It works well with hands, and on a narrow doorway. When the count goes over the CAPACITY, an alarm sounds.

What you need

  • 1Arduino Nano + base board
  • 1IR sensor module
  • 1Buzzer (optional)
  • 1Breadboard
  • 5Jumpers: 2 male-female, 3 female-female

Each part is described on Equipment.

Build it

  1. Unplug the USB.
  2. Wire the IR module to D2 as in Project 6 and the buzzer to D8.
  3. Stick the sensor on the side of a doorway, or hold it, with the front facing the opening.
  4. Upload. Pass your hand in front of it and watch the count go up.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Start here page.

People counter
// Project 14: People counter
// IR sensor OUT on D2, pointing across a doorway or at the spot where hands pass.
// Buzzer on D8 (optional). Each time something passes, the count goes up by one.
// If it passes the CAPACITY, the alarm sounds.

const int IR_PIN = 2;
const int BUZZER_PIN = 8;
const int SEES_THING = LOW;     // change to HIGH if your module works the other way round
const int CAPACITY = 5;

int people = 0;
bool wasBlocked = false;

void setup() {
  pinMode(IR_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(LED_BUILTIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("People counter ready. Count: 0");
}

void loop() {
  bool blocked = digitalRead(IR_PIN) == SEES_THING;

  if (blocked && !wasBlocked) {            // count when something arrives
    people++;
    Serial.print("Count: ");
    Serial.println(people);
    digitalWrite(LED_BUILTIN, HIGH);
    tone(BUZZER_PIN, 1000, 60);
    delay(120);
    digitalWrite(LED_BUILTIN, LOW);

    if (people > CAPACITY) {
      Serial.println("TOO MANY PEOPLE!");
      tone(BUZZER_PIN, 400, 700);
      delay(800);
    }
  }
  wasBlocked = blocked;
  delay(20);
}

What you should see

The Serial Monitor prints Count: 1, Count: 2... with a little beep and blink for each. After the sixth person it prints TOO MANY PEOPLE!

How it works

  • blocked && !wasBlocked is true only at the moment the beam is first blocked, so one person counts as one, even if they stay in front for a while.
  • people++ adds one to the count.
  • The alarm starts after people > CAPACITY, which is five by default.

If it does not work

It counts twice for one hand.

Move the hand quickly, or add a longer delay at the end of the loop.

It never counts.

Turn the little screw on the module until the module light comes on when your hand is close. Or change SEES_THING to HIGH.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.
