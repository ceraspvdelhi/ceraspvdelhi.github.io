6

Burglar alarm

An invisible beam that screams when somebody gets near.

No extra parts20 minLevel ★★☆

What you will make

The IR module sends out infrared light and looks for its reflection. When something is in front of it, the output pin changes. Most modules pull the pin LOW when they see something. There is a tiny screw (a trimmer) on the module that changes how far it can see.

What you need

  • 1Arduino Nano + base board
  • 1IR sensor module
  • 1Buzzer
  • 1Breadboard
  • 5Jumpers: 2 male-female, 3 female-female

Each part is described on Equipment.

Build it

  1. Unplug the USB. Wire the buzzer to D8 as in Project 5.
  2. Wire the IR module with three female-female jumpers to the D2 triplet: S to OUT, V to VCC, G to GND.
  3. Upload. You have five seconds to point the sensor at the door, then it is ARMED.
  4. Wave a hand in front of the sensor. If it never fires, turn the tiny screw on the module slowly until the small light on the module comes on when your hand is 10 cm away.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Getting started page.

Burglar alarm
// Project 6: Burglar alarm
// IR sensor OUT on D2, buzzer on D8 (long leg to the signal pin).
// Most IR obstacle modules pull the pin LOW when something is in front of them.
// If yours does the opposite, change SEES_THING to HIGH.
//
// You get 5 seconds after power-up to put the sensor in place.

const int IR_PIN = 2;
const int BUZZER_PIN = 8;
const int SEES_THING = LOW;
const int ARMING_SECONDS = 5;
const bool ACTIVE_BUZZER = false;

void siren() {
  for (int i = 0; i < 4; i++) {
    if (ACTIVE_BUZZER) {
      digitalWrite(BUZZER_PIN, HIGH);
      delay(150);
      digitalWrite(BUZZER_PIN, LOW);
      delay(100);
    } else {
      tone(BUZZER_PIN, 900, 150);
      delay(170);
      tone(BUZZER_PIN, 1500, 150);
      delay(170);
    }
  }
  noTone(BUZZER_PIN);
  digitalWrite(BUZZER_PIN, LOW);
}

void setup() {
  pinMode(IR_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(LED_BUILTIN, OUTPUT);
  Serial.begin(9600);
  Serial.print("Arming in ");
  Serial.print(ARMING_SECONDS);
  Serial.println(" seconds...");
  for (int s = ARMING_SECONDS; s > 0; s--) {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(100);
    digitalWrite(LED_BUILTIN, LOW);
    delay(900);
  }
  Serial.println("ARMED");
}

void loop() {
  if (digitalRead(IR_PIN) == SEES_THING) {
    Serial.println("INTRUDER!");
    digitalWrite(LED_BUILTIN, HIGH);
    siren();
    digitalWrite(LED_BUILTIN, LOW);
  }
}

What you should see

The Serial Monitor says ARMED, and then every wave of the hand sets off the siren and prints INTRUDER!

How it works

  • SEES_THING is LOW for most IR modules. If yours is the other way round, change it to HIGH.
  • setup() counts down five arming seconds, blinking the board light each second.
  • siren() plays two alternating notes four times. On an active buzzer it beeps instead.

If it does not work

It is always ringing.

The module is seeing the table or wall. Turn the screw to shorten its range, or point it into open space.

It never rings.

Check the small light on the module when you wave. If it flashes but the buzzer is quiet, the buzzer wiring is the problem. If it never flashes, check VCC and GND.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.
