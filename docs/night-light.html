Night light

A lamp that switches itself on when the room goes dark.

Resistor optional20 minLevel ★★☆

What you will make

The light sensor changes its number with the light. You need to find out two things: what number you get in the light, and what you get in the dark. Different modules read in different directions, so we look at the numbers first.

No resistors? No resistor needed when you use the light on the Nano. For a real LED, put it on D4 with a 220 Ω resistor and set LED_PIN to 4.

What you need

  • 1Arduino Nano + base board
  • 1Light sensor module (LDR)
  • 3Female-female jumpers
  • 1Optional: LED, 220 Ω resistor, breadboard

Each part is described on Equipment.

Build it

  1. Unplug the USB. Connect the sensor with three jumpers to the A0 triplet: S to the output labelled AO (or OUT), V to VCC, G to GND. If your module has four pins, use AO and not DO.
  2. Upload the code and open the Serial Monitor at 9600.
  3. Cover the sensor with your hand. Does the number go up or down? If it goes down, change DARK_GOES_UP to false.
  4. Note one number from a bright room and one from a dark room. Put THRESHOLD roughly halfway between.
  5. Upload again and test with your hand.

Tick each wire when it is done

Before you plug in the USB: every box above is ticked and no bare metal legs touch each other.
Always change wires with the USB unplugged. Orange is a signal wire, red is power (5 V) and dark is ground. Your real jumpers can be any colour.

The code

Open the Arduino IDE, delete everything in the window, paste this, and press Upload. Board settings are on the Start here page.

Night light
// Project 4: Night light
// The light sensor module (LDR) is on A0. When the room gets dark, the lamp turns on.
//
// Step 1: upload, open the Serial Monitor and cover the sensor with your hand.
// Does the number go UP or DOWN? Set DARK_GOES_UP below to match (true or false).
// Step 2: read the number in a bright room and a dark room, then set THRESHOLD between them.
//
// LED_BUILTIN is the light on the Nano. For a real LED with a 220 ohm resistor,
// plug it into D4 and change LED_PIN to 4.

const int LDR_PIN = A0;
const int LED_PIN = LED_BUILTIN;
const int THRESHOLD = 500;
const bool DARK_GOES_UP = true;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Night light ready. Cover the sensor and watch the number.");
}

void loop() {
  int light = analogRead(LDR_PIN);
  bool dark = DARK_GOES_UP ? (light > THRESHOLD) : (light < THRESHOLD);

  digitalWrite(LED_PIN, dark ? HIGH : LOW);

  Serial.print("light reading: ");
  Serial.print(light);
  Serial.println(dark ? "   -> dark, lamp ON" : "   -> bright, lamp OFF");
  delay(300);
}

What you should see

Cover the sensor and the light turns on. Uncover it and the light goes off. The Serial Monitor prints every reading.

How it works

  • analogRead gives a number from 0 to 1023. 0 is 0 volts, 1023 is 5 volts.
  • THRESHOLD is the line between "bright" and "dark". The sensor and the room decide where it should be, which is why we measure it first.
  • The condition (light > THRESHOLD) or (light < THRESHOLD) is picked by the DARK_GOES_UP flag, so the same sketch works for both kinds of module.

Try this

  • Print a bar of # signs in the Serial Monitor that grows with the light.
  • Add a delay so the lamp stays on for at least 5 seconds.
  • Use a real LED on pin 5 and fade it with analogWrite.

If it does not work

The lamp is always on or always off.

Check THRESHOLD against the numbers in the Serial Monitor, and check DARK_GOES_UP.

The number never changes.

You may have used the DO pin. Move the jumper to AO.

Nothing happens at all.

Check the power light on the Nano. Then check that the wires sit on the S, V and G of the same pin number, not a mix of two. Unplug the USB before you move any wire.
