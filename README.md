# SPV CERA Lab — Computers, Embedded Systems, Robotics & AI

A professional, school-oriented static project website for Sardar Patel Vidyalaya (independent prototype; not official school publication).

**Computers** encompasses both **Computer Science** and **Informatics Practices** (Python, SQL, Pandas, visualisation). The 15 implemented hands-on activities are Arduino Nano / embedded-systems projects; the other curriculum areas are introduced as learning tracks, not falsely represented as finished project packs.

## Preview
Open `docs/index.html` in a browser. The site works offline.

## GitHub Pages (no Git commands needed)
Create a repository, upload the contents of this folder through GitHub's web interface, and set Settings → Pages → Deploy from a branch → main → `/docs`.

## Content
15 instructional HTML projects, Arduino sketches, circuit diagrams and supporting site assets. Palette: rust `#A94922`, silver `#E4E4E4`, charcoal `#20272D`, off-white `#F7F7F5`.
