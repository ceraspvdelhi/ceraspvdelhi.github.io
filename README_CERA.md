# SPV CERA Lab — Project Collection

A redesigned static educational website containing 15 Arduino practical projects, with a restrained saffron-rust / silver / charcoal visual identity.

## Open
Open `docs/index.html` in a modern browser. No server is required.

## Deploy
Upload all files to a repository, then configure GitHub Pages to serve the `/docs` folder. The published site uses stylesheets in `docs/assets` and inline page scripts. Publish the `docs` directory with GitHub Pages.

## Components
- 15 project pages and navigation
- Arduino .ino sketches in `/sketches`
- Wiring diagrams, parts lists and tutorials
- Copy / download code actions
- Browser-only progress tracking

## Palette
Rust #A94922; Silver #E4E4E4; Charcoal #20272D; Off-white #F7F7F5.
