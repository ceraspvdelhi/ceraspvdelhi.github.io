# SPV Engineering Lab — Arduino Project Collection

A professional, responsive educational interface for 15 Arduino Nano practical activities.

**Status:** Independently prepared SPV-branded draft; not an official school publication or endorsement.

## Preview and deploy

- Open `docs/index.html` in a browser.
- For GitHub Pages, publish the repository root `docs/` directory on the main branch.
- All pages are static and function without a build process; external Google Fonts fall back to system fonts when offline.
- Sketch source code is preserved in `sketches/`.

## Contents

- 15 project pages with procedures and embedded Arduino sketches
- Setup guidance, component details and educational material
- Responsive navy / ivory academic visual system
- Local browser progress tracking retained from the source
